## 코드와 실행 기록의 버전

루트의 빌드 가능한 코드는 원본 main `17c6d7fc0996e389fdf025de8a926974f9186b79`에서 동기화했습니다. [동기화 범위](../product-source.md)에서 포함 파일과 제외 항목을 확인할 수 있습니다.

이 폴더의 수신 상한과 만료 정리 코드는 과거 진단 브랜치에서 추출한 부분입니다. 단독 빌드 파일이나 공개 루트에 적용할 패치가 아닙니다. 진단 수정을 제품 main에 합치지 않았고 기록의 실행 버전을 현재 공개 커밋으로 바꾸지 않았습니다.

## 공개 방법

실행 기록에서 측정값과 버전 식별자를 선별했습니다. 계정 번호와 운영 주소 및 인증 정보는 포함하지 않았습니다. 내부 실행 원문과 비공개 링크도 공개하지 않았습니다.

수신 비교와 용량 JSON은 기존 기록에서 선택한 필드를 담은 공개용 사본입니다. 복구 JSON은 익명화된 DB 조회 기록에서 선택했습니다. 세 JSON에는 원본 blob을 기록했고 RSS manifest에는 원본 경로와 blob 및 분석 창을 기록했습니다. RSS TSV 세 개는 원본 파일의 byte-identical 사본입니다. 해시는 사본을 구분하는 식별자이지 실행 사실을 독립적으로 입증하는 서명이 아닙니다.

[공개 파일 목록](publication-manifest.json)에 파일별 SHA-256을 기록했습니다. 공개용 검사는 파일 내용의 일치와 필드 관계만 확인합니다. 과거 부하와 Unity 복구 실험을 다시 실행하는 검사가 아닙니다.
