## 코드와 실행 기록의 버전

루트의 빌드 가능한 코드는 2026-08-13 공개 기준입니다. 이 폴더의 후속 사례를 추가했다고 루트 코드를 측정 버전으로 교체한 것은 아닙니다. 후속 제품 코드 전체의 공개 동기화는 아직 완료하지 않았습니다.

이 폴더의 코드는 원문에서 추출한 부분입니다. 단독 빌드 파일이나 공개 루트에 적용할 패치가 아닙니다. 기록의 실행 버전을 현재 공개 커밋으로 바꾸지 않았습니다.

## 공개 방법

실행 기록에서 측정값과 버전 식별자를 선별했습니다. 계정 번호와 운영 주소 및 인증 정보는 포함하지 않았습니다. 내부 실행 원문과 비공개 링크도 공개하지 않았습니다.

수신 비교와 용량 JSON은 기존 기록에서 선택한 필드를 담은 공개용 사본입니다. 복구 JSON은 익명화된 DB 조회 기록에서 선택했습니다. 각 파일에 출처 문서의 Git blob SHA와 추출 범위를 남겼습니다. 해시는 사본을 구분하는 식별자이지 실행 사실을 독립적으로 입증하는 서명이 아닙니다.

[공개 파일 목록](publication-manifest.json)에 파일별 SHA-256을 기록했습니다. 공개용 검사는 파일 내용의 일치와 필드 관계만 확인합니다. 과거 부하와 Unity 복구 실험을 다시 실행하는 검사가 아닙니다.
